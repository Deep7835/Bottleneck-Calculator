# Bottleneck Calculator

A static CPU/GPU bottleneck and FPS calculator site. There's no backend and no framework, so it works on any static host (Cloudflare Pages, Netlify, Vercel or shared hosting). Lighthouse scores 100 in all four categories on the homepage, the FPS calculator, build pages and trust pages (mobile preset, served with gzip).

## Before you publish

Run the build once with your real domain (trailing slash required):

```bash
SITE_URL=https://www.yourdomain.com/ node scripts/build.js
```

This replaces the `example.com` placeholder in canonical tags, Open Graph tags, schema and the contact email, and writes `sitemap.xml` and `robots.txt`. Then fill in the `<!-- OWNER: -->` notes on the trust pages.

## After editing CSS or JS

Bump the `?v=` number on the asset links (all pages share one number) so returning visitors don't get a stale cached copy:

```bash
sed -i '' -E 's/\?v=16"/?v=17"/g' index.html 404.html */index.html scripts/*.js
node scripts/build.js
```

## Updating hardware

1. Add a row to `assets/js/hardware.js`. CPU index: Ryzen 7 9800X3D = 100. GPU index: RTX 4090 = 100.
2. Run `node scripts/build.js` so the static tables, build pages and sitemap pick up the change.
3. Update the "Data updates" section and the `dateModified` in `index.html`.

## Shareable URLs

`?cpu=ryzen-7-7800x3d&gpu=rtx-5070-ti&res=4k&q=ultra&game=raytracing&up=quality&ram=32&hz=144&stream=1&disk=hdd`

Only `cpu` and `gpu` are required. IDs are the part names lowercased with the brand removed.
